### How Classmoji maps to Github

If you've used Github before, Classmoji will feel familiar. Every Classmoji concept has a Github counterpart: an organization holds repositories, and each student's work happens in one.

<GithubMappingDiagram />

A Github organization is a Classmoji classroom, and a Github repository is a Classmoji repository. Assignments are Classmoji's own layer on top: a student submits one by pushing to their repo, or, in issue mode, by closing an issue Classmoji opened there. On the people side, org members are your students and Github teams are your teams.

Everything stays in Github where your code already lives.

### Classrooms

A classroom is scoped to a Github organization, but one org can hold multiple classrooms. For example, a teacher might use the same Github organization for the same course they teach in different semesters.

### Repositories

A repository is storage backed by a Github repo. It points at a template that Classmoji copies to each student or team when you publish it. It carries no weight and no grades; several assignments can submit through the same repository.

### Modules

A module is a week or a unit: an ordered list of pages, slide decks, and assignments. Every assignment lives in a module, and students reach everything through their Modules view. A module isn't backed by a Github repo. Modules stay hidden until you publish them.

### Assignments

An assignment is one graded piece of work. It has a type, **repository**, **quiz**, or **form**, and carries the weight, release date, deadlines, and token rate. A repository assignment is submitted by pushing to the student's repo (push mode) or by closing a Github issue Classmoji opened there (issue mode). The course grade is the weighted mean of the graded assignments, plus extra credit.

### Grading

Classmoji grades with emoji: each emoji maps to a number, and a submission's grade is the mean of the emoji it was given. The goal is feedback that feels less punitive and more expressive. If you've only ever graded with numbers, this feels weird for about one week. Then you won't want to go back. If you'd rather not, a built-in 0–100 scale is one click away.

### Tokens

Tokens are a flexible deadline extension system. Students get a set number of tokens per term and spend them to push due dates, no email required. Assign them at the start of the semester and your inbox stays quiet.

### Memberships and Roles

Everyone in a classroom has a role: Owner, Teacher, Assistant, or Student. Roles control what each person can see and do. The Owner created the classroom and has full control. Teachers are teaching staff with broad access to run the classroom. Assistants can grade but not configure the classroom. Students can only access their own work.
